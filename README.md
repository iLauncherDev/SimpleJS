# What is SimpleJS

SimpleJS is a JavaScript-like scripting language designed to run your scripts with low memory usage.

### Features

- [x] Plugins support
- [x] Bytecode virtual machine
- [x] Garbage collector
- [x] Basic compile-time diagnostics
- [x] Basic runtime diagnostics
- [x] Compatible with MSVC compiler
- [x] Compatible with MinGW compiler
- [x] Compatible with POSIX compiler
- [x] Public API for developing SimpleJS plugins
